Narration Studio: Languages

English voices app

Cast

On-device voices can be mixed, overlapped and saved as a .wav, but each language has only one voice. System voices (from your browser or operating system) have more variety and cover Mandarin and Arabic, but they only play live: no saving, no overlaps. If any line uses a system voice, the whole script plays live.

Script

Directions: what you can write in the script
Name: line

Character speaks the line. Lines without a name use the Narrator. Use the buttons above the text box to add one.

[pause 1.5]

Silence for that many seconds, on its own line.

[overlap] Name: line

The line starts before the previous one ends. [overlap 1] starts it 1 second early (default 0.6). Only works when every line uses an on-device voice.

blank line

A short pause between paragraphs.

[anything else]

Other bracketed text is skipped, not read aloud.

On-device models run in your browser with no account or API key. The models here are Meta's MMS voices, which are licensed for non-commercial use only.

On-device models

A model id with a slash, like Xenova/mms-tts-spa, downloads from Hugging Face the first time (about 38 MB) and is then cached. An id without a slash, like mms-tts-hil, loads from a models folder in your own GitHub repo. Tagalog and Hiligaynon need that: they have to be converted first with the convert_mms.py script. The sample text is what Preview speaks, so edit it if my wording is off.
