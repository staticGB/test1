Script

Directions: what you can write in the script
Name: line

Character speaks the line. Use the character buttons above the text box to add one.

[pause 1.5]

Silence for that many seconds. Put it on its own line.

[overlap] Name: line

The line starts before the previous one ends, like someone cutting in. [overlap 1] starts it 1 second early. The default is 0.6.

blank line

A short pause between paragraphs.

[anything else]

Other bracketed text is skipped, not read aloud. The voices can't be told how to feel.
